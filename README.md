# HireSense-AI

AI-powered Resume ATS Analyzer built using React, TypeScript, FastAPI, Python, PostgreSQL, and JWT Authentication.

## Features
- Resume Upload
- ATS Score
- Job Description Matching
- Skill Gap Analysis
- Recruiter Verdict
- Resume Strength Analysis
- PDF Report Generation
- Resume History
- User Authentication

## Tech Stack
- React
- TypeScript
- Tailwind CSS
- FastAPI
- Python
- PostgreSQL (Neon)
- JWT
- ReportLab
